# Dessert Vote 🍰

Secret yes/no vote for dessert at a restaurant. Pass one phone around the table; each person votes privately. If **more than half** vote yes, the table gets dessert (a tie means no).

No more "ohhh idk, I guess if you want something I'll have a bit."

**Play it:** https://emcl-justin.github.io/dessert-vote/

Single self-contained `index.html` — no build step, no backend.
